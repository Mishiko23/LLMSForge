# LLMS Forge для MODX 3

Бесплатное дополнение для создания `/llms.txt` и отдельных Markdown-карточек страниц. Лицензия — GPL-3.0, полный текст в [`COPYING`](COPYING). Издатель: [Mishiko23](https://github.com/Mishiko23).

## Возможности

- Основной файл собирается из выбранных ресурсов MODX или редактируется вручную. До 5000 выбранных ID, поиск по загруженному каталогу и разделы.
- Для товаров, категорий и статей можно создать отдельные карточки `/llms-txt/slug`. В карточках из ресурсов доступны содержимое, выбранные TV и поля miniShop3 `price`, `old_price`, `article`, `weight`, `vendor`, `made_in`. До 200 карточек, до 50 КБ Markdown в каждой и до 60 КБ метаданных карточек вместе.
- В панели доступны массовое создание карточек, предпросмотр, скачивание, проверка установки и статистика обращений известных AI-ботов.
- Настройки разделены по контекстам MODX. Публичные маршруты обслуживает MODX; физический файл в корне сайта не создаётся.

`llms.txt` — рекомендательный формат для AI-агентов. Публикация не гарантирует индексацию или цитирование. Журнал обращений определяет ботов по User-Agent без проверки IP и фиксирует только запросы, дошедшие до MODX.

## Требования

MODX Revolution 3, PHP 8.1+, расширения DOM, JSON и mbstring, работающий Friendly URLs. Веб-сервер должен перенаправлять неизвестные пути `/llms.txt` и `/llms-txt/…` в MODX. Существующий файл или ресурс с тем же адресом имеет приоритет. Для журнала PHP нужен доступ на запись в `core/components/llmsforge/var/visits`.

## Установка и обновление

1. Установите transport-пакет через **Пакеты** в MODX 3.
2. Откройте **Компоненты → LLMS Forge**, выберите контекст и нажмите **Проверить**.
3. Укажите название и описание сайта, выберите страницы либо введите Markdown вручную. При необходимости задайте TV и поля miniShop3.
4. Просмотрите результат, включите публикацию и сохраните настройки.
5. Проверьте публичный `/llms.txt` и одну карточку `/llms-txt/slug` в анонимном браузере.

При обновлении установите новый пакет поверх прежнего. Настройки контекстов сохраняются. Если ранее был создан ресурс с URI `llms.txt` и сниппетом `LLMSForge`, он имеет приоритет перед маршрутом плагина. Такой ресурс нужно обслуживать отдельно.

## Безопасность и ограничения

Автоматический экспорт исключает неопубликованные, удалённые, закрытые группой, недоступные по правам, не участвующие в поиске и скрытые датами ресурсы. Проверяются также родительские ресурсы. Событие `OnLLMSForgeResourceCheck` позволяет интеграторам дополнительно исключать страницы. HTML преобразуется в Markdown без выполнения сниппетов.

Ручная карточка публикуется как самостоятельный текст: изменение прав или публикации исходной страницы не скрывает её автоматически. Для карточек, зависящих от ресурса, используйте режим **Получать из ресурса MODX**. WebLink и SymLink не разворачиваются в целевой ресурс; StaticResource не читает содержимое файла. Поля miniShop3 добавляются только в автоматические карточки, а не в строки основного `/llms.txt`.

Журнал хранит данные до 30 дней, не сохраняет IP, параметры URL, cookies и полный User-Agent. Лимит записи — 5 МБ в сутки; при достижении лимита новые события пропускаются. Это статистика запросов, а не подтверждение чтения или использования содержимого AI-системой.

## Сборка из исходников

На установленном MODX 3 выполните `php _build/build.transport.php /path/to/modx/config.core.php`. Архив появится в `core/packages`. Скрипт `_build/smoke.install.php` устанавливает пакет для интеграционной проверки; `_build/smoke.runtime.php` создаёт временные тестовые записи внутри транзакции и откатывает их.

Локальные проверки: `php tests/renderer.php`, `php tests/manager.php`, `php tests/documents.php`, `php tests/html.php`, `php tests/visits.php`. Браузерный тест `node tests/interface.cjs` использует Playwright и Chrome/Chromium и имитирует API MODX. Он проверяет в том числе каталог из 5000 страниц.

Подробная проверка релиза — в [`docs/release-checklist.md`](docs/release-checklist.md). История изменений — в [`CHANGELOG.md`](CHANGELOG.md). English documentation: [`docs/README.en.md`](docs/README.en.md).
