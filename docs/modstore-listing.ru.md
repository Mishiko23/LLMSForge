# LLMS Forge — генератор llms.txt для MODX 3

Бесплатное дополнение создаёт Markdown-путеводитель по сайту для AI-агентов. Управляйте составом `/llms.txt` из панели MODX и публикуйте отдельные Markdown-описания важных страниц.

Возможности: автоматическая сборка из выбранных ресурсов или ручной Markdown; группировка по разделам, поиск и массовый выбор; отдельные карточки `/llms-txt/…` для товаров и статей; предпросмотр; поддержка контекстов; журнал обращений известных AI-ботов по User-Agent за 30 дней.

Дополнение не гарантирует индексацию или цитирование AI-системами. Журнал фиксирует запросы, которые дошли до MODX; User-Agent может быть подделан. Автоматический режим использует общие поля ресурсов MODX. Цены, остатки и характеристики miniShop3, TV и результат работы сниппетов не извлекаются.

Требования: MODX Revolution 3, PHP 8.1+, поддержка Friendly URLs. Маршруты `/llms.txt` и `/llms-txt/…` должны перенаправляться веб-сервером в MODX. Для журнала нужен доступ PHP на запись в `core/components/llmsforge/var/visits`.

Установка: через менеджер пакетов MODX после публикации transport-пакета на modstore.pro. Откройте «Компоненты → LLMS Forge», задайте название и описание сайта, выберите страницы, просмотрите результат, включите публикацию и сохраните. Проверьте публичный `/llms.txt` и диагностику установки в модуле.

Сценарии: документация компании; витрина товаров с отдельными карточками для ключевых позиций; блог со статьями; многоязычные сайты с отдельной настройкой каждого контекста.
