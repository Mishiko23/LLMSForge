# LLMS Forge — карточка для modstore.pro

## Название

LLMS Forge — генератор llms.txt для MODX 3

## Краткое описание

Публикует llms.txt и Markdown-карточки страниц из панели MODX 3. Поддерживает товары miniShop3, разделы и статистику запросов AI-ботов.

## Полное описание

LLMS Forge помогает подготовить содержимое сайта для AI-агентов. Дополнение публикует `/llms.txt` со ссылками на выбранные страницы и отдельные Markdown-карточки для товаров, категорий, статей и других ресурсов MODX. Настройка выполняется в панели управления без ручного редактирования файлов на сервере.

### Возможности

- Сборка основного документа из ресурсов MODX или ручной Markdown.
- Поиск по названию и ID, массовый выбор, исключения и группировка ссылок по разделам. Можно выбрать до 5000 ресурсов; панель загружает до 10 000 записей каталога.
- До 200 отдельных карточек `/llms-txt/slug`: ручной текст или автоматическое содержимое ресурса. Карточки можно создавать массово.
- Для автоматических карточек доступны выбранные TV и поля miniShop3: `price`, `old_price`, `article`, `weight`, `vendor`, `made_in`. Цена товара выводится в карточке, а не рядом со ссылкой в основном `/llms.txt`.
- Предпросмотр и скачивание Markdown, диагностика установки, отдельные настройки для каждого контекста MODX.
- Журнал запросов известных AI-ботов: время UTC, имя бота, путь, метод и статус ответа за последние 30 дней.

### Где пригодится

- **Интернет-магазин:** ссылки на ключевые категории и Markdown-карточки товаров с ценой и артикулом miniShop3.
- **Сайт компании:** разделы услуг, важных страниц и контактов в одном документе.
- **Блог или база знаний:** подборка статей и подробные карточки материалов.

### Установка

Установите пакет через менеджер пакетов MODX 3. Откройте **Компоненты → LLMS Forge**, выберите контекст, запустите проверку, укажите название сайта и выберите страницы. Просмотрите результат, включите публикацию и сохраните настройки. Затем проверьте `/llms.txt` в браузере без авторизации.

### Требования и особенности

MODX Revolution 3, PHP 8.1+, расширения DOM, JSON и mbstring, работающие Friendly URLs. Веб-сервер должен передавать неизвестные адреса `/llms.txt` и `/llms-txt/…` в MODX. Для журнала запросов PHP нужен доступ на запись в `core/components/llmsforge/var/visits`.

Публичные адреса обслуживает MODX: физический файл `llms.txt` в корне сайта не создаётся. Автоматический экспорт учитывает публикацию, даты, права доступа, группы ресурсов и доступность родительских страниц. Ручная Markdown-карточка публикуется независимо от состояния исходного ресурса.

Формат `llms.txt` рекомендательный. Публикация не гарантирует индексацию или цитирование AI-системами. Журнал определяет ботов по User-Agent без проверки IP и учитывает только запросы, дошедшие до MODX. IP-адреса, параметры URL, cookies и полный User-Agent не сохраняются.
