# Проверка перед отправкой на modstore.pro

- [x] Выбрать лицензию распространения: GPL-3.0. Текст в COPYING.
- [ ] Указать имя правообладателя в карточке modstore.pro.
- [ ] Установить чистый MODX 3 с PHP 8.1+ и собрать `llmsforge-*.transport.zip` через `_build/build.transport.php`.
- [ ] Установить transport-пакет через «Установщик», проверить меню, сниппет, плагины, настройки и запись журнала.
- [ ] Проверить обновление поверх 0.4.x с сохранением контекстных настроек и журнала.
- [ ] Проверить удаление через менеджер пакетов, затем повторную установку.
- [ ] Проверить `/llms.txt`, `/llms-txt/slug`, тип ответа `text/plain`, GET/HEAD и 404 для неизвестных карточек.
- [ ] Проверить два контекста, закрытые ресурсы, сроки публикации, товары miniShop3, страницы с пустым описанием.
- [ ] Проверить Apache и nginx с реальными правилами перенаправления в MODX.
- [ ] Сделать реальные скриншоты админки для карточки дополнения; текущий `admin-preview.png` создан с тестовыми данными.
- [ ] После прохождения проверок заменить `alpha` на `pl`, обновить номер версии и changelog.
- [ ] Загрузить transport-пакет и описание в личном кабинете modstore.pro; отправить на модерацию.

Текущий архив `*-installer.zip` — исходники для ручной установки. Он не является transport-пакетом для modstore.pro. Тестовая база MODX 3 в текущем рабочем каталоге отсутствует.
