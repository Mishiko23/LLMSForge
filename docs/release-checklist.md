# LLMS Forge 1.0.0-pl — проверка релиза

Проверки выполнены 4 ноября 2026 года на MODX 3 / PHP 8.3 сайта `moysklad.dev23.ru`, если не указано иначе.

## Выполнено

- [x] GPL-3.0: полный текст в `COPYING`; издатель в документации — Mishiko23.
- [x] Transport-пакет `llmsforge-1.0.0-pl.transport.zip` собран на MODX 3 и установлен поверх 0.6.6-alpha. Повторная установка прошла; настройки контекста сохранились.
- [x] Пользователь подтвердил работу установки и удаления на своём сервере. Автоматический тест удаления на отдельной чистой установке не проводился.
- [x] Публичный nginx и прямой Apache: `/llms.txt` и существующая `/llms-txt/resource-1` отвечают `200 text/plain; charset=utf-8`; неизвестная карточка — `404`. HEAD на обоих существующих маршрутах отвечает `200 text/plain`.
- [x] Интеграционный тест с откатом транзакции: два контекста, неопубликованные ресурсы, даты публикации и снятия, группа ресурсов, скрытый родитель, пустое описание и цена miniShop3.
- [x] Локальные PHP-проверки и браузерный тест интерфейса, включая имитацию каталога из 5000 страниц.
- [x] Русская и английская документация, карточка для modstore.pro и changelog обновлены под фактические возможности.

## Перед отправкой в modstore.pro

- [ ] Подготовить актуальный снимок установленной панели MODX. `docs/admin-preview.png` — снимок интерфейса с демонстрационными данными; он не выдаётся за реальный сайт.
- [ ] Проверить итоговый текст карточки и отображаемое имя правообладателя в аккаунте modstore.pro.
- [ ] Загрузить transport-пакет и описание в личном кабинете modstore.pro и отправить на модерацию. Нужен доступ к аккаунту издателя.

## Известные границы проверки

- Производительность на реальной базе с 5000 опубликованных страниц не измерена. Тест интерфейса использовал 5000 записей, а тест генератора с 5000 ID на сайте содержал в основном несуществующие ID.
- Английский перевод панели частичный: названия настроек и основная навигация переведены, часть сообщений и пояснений остаётся на русском. Это нужно учитывать при публикации для англоязычной аудитории.
