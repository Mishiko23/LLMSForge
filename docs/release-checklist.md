- [ ] Указать имя правообладателя в карточке modstore.pro.
- [x] Собрать `llmsforge-0.6.4-alpha.transport.zip` на тестовом MODX 3 / PHP 8.3 через `_build/build.transport.php`.
- [x] Установить transport-пакет на тестовом MODX и проверить меню, сниппет, плагины, публичный маршрут и запись журнала.
- [x] Повторить установку поверх ранее установленного модуля; существующие название и описание сайта сохранились.
- [ ] Проверить удаление через менеджер пакетов, затем повторную установку.

- [ ] Проверить два контекста, закрытые ресурсы, сроки публикации, товары miniShop3, страницы с пустым описанием.

- [ ] После прохождения проверок заменить `alpha` на `pl`, обновить номер версии и changelog.
- [ ] Загрузить transport-пакет и описание в личном кабинете modstore.pro; отправить на модерацию.

В `dist/` локально находится собранный transport-пакет для дальнейшей проверки и подачи на modstore.pro. Он не включён в Git. Проверка удаления остаётся открытой, чтобы не затронуть данные используемого тестового сайта.
